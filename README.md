# Saktah Space — Official Website

> **Clean Space, Clear Impact.**  
> Islamic Creative Agency & Digital Creative Studio.

---

## 1. Ikhtisar Proyek

Repositori ini memuat kode sumber website profil resmi untuk **Saktah Space**. Situs ini dibangun dengan filosofi desain **"Quiet Confidence"**—mengutamakan ketenangan visual, ruang baca yang lapang, kejujuran narasi, dan kepatuhan terhadap etika bisnis Islam tanpa sensasionalisme berlebih.

---

## 2. Struktur Direktori

```
Saktah Space/
├── index.html              # Struktur semantik HTML5 halaman utama
├── README.md               # Dokumentasi proyek & panduan pengembangan
├── css/
│   └── style.css           # Design tokens, CSS reset, dan stylesheet utama
├── js/
│   └── main.js             # Skrip interaksi vanilla JS (navigasi, filter, i18n)
└── assets/
    ├── images/
    │   └── logosaktah.svg  # Master vektor logo asli Saktah Space
    ├── icons/              # Aset ikon SVG tambahan
    └── fonts/              # Aset font lokal (jika diperlukan)
```

---

## 3. Palet Warna Resmi (Brand Tokens)

* **Deep Forest Green**: `#344C38` (Identitas utama & kanvas penutup)
* **Warm Ivory**: `#F4EFDC` (Latar belakang utama website)
* **Soft Sand**: `#EAE4CF` (Permukaan kartu kontras lembut)
* **Muted Sage**: `#8FA28F` (Aksen, lencana, dan penanda alur)
* **Charcoal Forest**: `#1C241E` (Warna teks utama berdaya baca tinggi)

---

## 4. Standar Kode & Panduan Pengembangan

* **Standar HTML**: HTML5 Semantik (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<details>`, `<footer>`).
* **Aksesibilitas**: Mematuhi panduan WCAG 2.1 AA (kontras warna tajam, `aria-label`, target sentuh memadai).
* **Teknologi**: Vanilla HTML, CSS murni (tanpa framework/Tailwind tanpa persetujuan), dan Vanilla JavaScript murni.
